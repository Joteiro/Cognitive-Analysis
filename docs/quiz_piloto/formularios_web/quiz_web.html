Antes de empezar

Este cuestionario es parte de un estudio (un trabajo de fin de master) sobre cuanto recordamos de los videos que vemos. Vas a ver unos videos cortos y despues responder algunas preguntas de memoria.

Se guardan tus respuestas, el tiempo que tardas y cuando viste cada video, de forma anonima (bajo un seudonimo, sin tu nombre). Los datos se usan solo de forma agregada para el estudio. Es voluntario y podes dejarlo cuando quieras cerrando la pagina.
